# Home

## Purpose

Provide a simple visual entry point to the information stored in Cal Menut.

## Content

- Masia
- Infraestructures
- Equips
- Gestions
- Arxiu
- Search button
- Application version
- Last deployment date

## Notes

- User-facing text is in Catalan.
- Use large icons and generous spacing.
- No dashboard, live data, status, timeline or task information.
- Search is local and deliberately small for this milestone.
